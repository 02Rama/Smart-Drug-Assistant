# 💊 Smart Drug Assistant

A lightweight, single-page web app that helps people look up medicines, learn how to use them safely, and scan a QR code to jump straight to a medicine's info page — from their phone's camera or from within the app itself.

Built as a single self-contained `index.html` file: no build step, no backend, no dependencies to install. Open it in a browser and it works.

---

## ✨ Features

- **Medicine library** — browse and search a set of common medicines, each with dosage form, strength, drug class, active ingredient, uses, warnings, and interactions.
- **Insulin Guide** — step-by-step guidance and video reference for insulin types and injection technique.
- **Asthma Inhaler Guide** — proper inhaler technique walkthrough with video reference.
- **QR code lookup**
  - Every medicine has its own generated QR code, viewable on its detail page or all together on a printable QR sheet.
  - Scan with the app's **built-in camera scanner**, or with your **phone's regular camera app** — either way, it opens straight to that medicine's page.
  - A **manual code entry** fallback lets you look up a medicine by typing its code (e.g. `SDA-MED-01`) if a camera isn't available.
- **Deep linking** — opening the page with `?med=<code>` in the URL (which is exactly what the QR codes encode) jumps directly to that medicine, so the app can be linked to or bookmarked per-medicine.
- **Responsive, mobile-first UI** — designed to feel like a native mobile app inside the browser.

## 🚀 Getting Started

### Option 1 — Just open it
Download `index.html` and open it directly in any modern browser. Everything except QR generation/scanning and camera access will work immediately.

### Option 2 — Run it locally with a server (recommended)
Camera access (`getUserMedia`) and reliable QR behavior require a proper origin — most browsers block camera access on `file://` pages. Serve the folder locally instead:

```bash
# Python
python3 -m http.server 8000

# Node
npx serve .
```

Then open `http://localhost:8000` in your browser.

### Option 3 — Deploy it (needed for QR codes to work from other phones)
QR codes encode a link back to this page (`your-deployed-url/?med=SDA-MED-01`). For a QR code to open correctly on **someone else's phone**, the page must be hosted at a real, public URL — not opened as a local file. Any static hosting works, for example:

- [GitHub Pages](https://pages.github.com/)
- [Netlify Drop](https://app.netlify.com/drop)
- [Vercel](https://vercel.com/)

Once deployed, every QR code generated by the app will automatically encode the live URL.

## 🛠 Tech Stack

- Vanilla HTML, CSS, and JavaScript — no framework, no build tooling
- [`qrcodejs`](https://github.com/davidshimjs/qrcodejs) — QR code generation
- [`jsQR`](https://github.com/cozmo/jsQR) — camera-based QR code decoding
